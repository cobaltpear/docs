Cobalt Pear is free to use: every model in the list and one worker of your own.
**Plus** is for when you want more than that. It is a file you add to the same page, not a different app.

## What it costs
<s>$29</s> **$19** launch price until December 31, 2026, paid once.
You get 12 months of updates or more from the day you buy.
[Get Plus ↗](https://cobaltpear.gumroad.com/l/plus/LAUNCH)

## What it adds
- **Any number of your own workers.** Free takes one. Models from the list never count.
- **Fine-tune.** Change LoRA strengths and a model's own values (steps, CFG, sampler …) in one place. With it off, every model runs as its maker set it, and LoRAs at 0.8.
- **[Bulk requests](/docs/bulk-requests/).** Send many prompts at once. RunPod makes them when it has room, and they come in even if you close the page.
- **Workers on Modal.** Run a worker on [Modal](https://modal.com) instead of RunPod. Settings has a setup file that puts the worker there for you.

## Add it
1. After you buy, download the Plus file from Gumroad. It ends in `.json`.
2. In Cobalt Pear, go to **Settings** → **Plugins** → **Add a plugin file…** and pick that file.
3. Plus shows in the list, and its switches appear under it in Settings.

Take the Plus file only from **cobaltpear.gumroad.com** or **cobaltpear.github.io**. Cobalt Pear takes only a file we signed. A file from anywhere else may leak your RunPod key.

## Updates
A new Plus file comes out from time to time. Download it from Gumroad again and add it the same way. It replaces the old one.
