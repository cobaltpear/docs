---
title: Bulk requests
description: Send many prompts at once — RunPod makes them when it has room, and they come in even if you close the page.
---

With **Bulk requests** ([Plus](/docs/plus/)), you send many prompts at once. RunPod gets them all as one batch and makes them when it has room.
This can take a while, so it suits a big set you don't need right away.

## Turn it on
**Settings** → tick **Bulk requests**. A **×1** box appears next to **Seed**.

## Write the prompts
- One prompt per line.
- `×3` at the end of a line makes 3 of that prompt. A line without it makes the number in the **×1** box.
- With a **Seed**, each picture of a line counts up from it: 100, 101, 102 …
- Every chosen model makes each one.

```
a woman reading in a cafe
an old fisherman on the pier ×10
a red bicycle in an alley ×2
```

## Closing the page
- **Once they show «Bulk request»**, they are on RunPod. You can close the page or the browser. RunPod keeps making them.
- **Open Cobalt Pear again in the same browser.** It picks them up and the finished ones come in by themselves. The list of what you sent is kept only in that browser, so another browser or a private window can't see them.
- **Don't wait too long.** RunPod keeps finished results only for a limited time. If they are gone, the result says *RunPod no longer has this request*.
- **Closed in the second right after sending**, before they showed «Bulk request»? Then they never started, and nothing is charged. Send them again.

## Models on Modal
Modal has no bulk requests. Their pictures are made the usual way, a few at a time, and only while the page is open. If you close the page, those results are lost.
