# Cobalt Pear manual

The manual for [Cobalt Pear](https://cobaltpear.github.io/), read it at **https://cobaltpear.github.io/docs/**.

Pages are Markdown files in `src/content/docs/`, built with [Starlight](https://starlight.astro.build/).
Each push to `main` publishes the site.

```sh
npm install
npm run dev     # preview at localhost:4321/docs
```
